# 局域网协作使用说明

最短路径：先让几台电脑加入同一个协作组；如果要同步照片，再用“绑定同一项目”交换项目码；最后回到照片工作区点“同步当前编号”或“同步项目”。

## 核心概念

协作分两层：

- **团队协作组**：同一组码的电脑可以看到彼此在线状态、编号任务、负责人和进度。
- **项目同步码**：照片、TIF、ZIP 只在同一个项目同步码之间同步。

同一个团队可以同时拍多个项目。此时顶栏“协作”会显示全部同组设备，但不同项目同步码的设备只同步任务状态，不同步照片文件。

## 是否需要相同目录

不需要。两台电脑的绝对路径可以不同：

```text
电脑 A: D:\Photos\Project-A
电脑 B: N:\specimen\Project-A
```

软件按项目内部相对路径同步，例如：

```text
incoming-jpg/ABC001_001.jpg
results/ABC001-1-20260705.tif
results/ABC001-1-20260705.zip
```

## 推荐流程

1. 第一台电脑创建项目并启用协作。
2. 其它电脑使用同一份项目副本，或从同一项目目录继续工作。
3. 所有电脑设置相同协作组码。
4. 如果另一台电脑是独立创建的同一项目，在顶栏“协作”点击“绑定同一项目”：
   - 已有正确项目的电脑点击“复制本机同步码”。
   - 另一台电脑粘贴到“加入队友项目同步码”，确认后即可成为同一项目。
5. 在顶栏“协作”确认设备在线，并查看“照片”列：
   - `可同步`：同组且项目同步码相同，可以同步照片。
   - `仅任务`：同组但项目同步码不同，只同步编号/状态。
6. 在工作台使用“同步当前编号”或“同步项目”拉取照片、TIF、ZIP。

## 冲突规则

- 缺失文件会自动下载。
- 相同路径且哈希一致的文件会跳过。
- 相同路径但内容不同会标记冲突，不会静默覆盖。
- 选择“强制覆盖本机”时，本机旧文件会先备份到 `_data/sync-conflicts/`。

## 常见问题

- 看得到队友但不能同步照片：通常是项目同步码不同，只能同步任务。
- 目录盘符不同：没关系，只要使用同一个项目同步码即可。
- 同名项目不能同步：说明它们是独立创建的项目。确认确实是同一项目后，用“绑定同一项目”处理。
