# 项目树结构优化说明（非功能性）

本文件用于记录仓库树结构意图，避免“路径歧义”导致后续误改。

## 设计原则

- **功能目录不变**：本次优化不调整运行时行为与业务逻辑。
- **边界单一来源**：每类资产集中在约定目录，便于检索与审计。
- **新文件有约定入口**：避免再引入空目录导致结构噪音。

## 建议的扫描规则

- `app/`
  - `config/`: 运行与界面配置
  - `db/`: 数据库初始化与 schema
  - `models/`: 持久化数据对象
  - `services/`: 业务编排与服务
  - `utils/`: 与业务无关通用工具
  - `views/`: 页面逻辑（主视图/对话框）
  - `widgets/`: 可复用 UI 组件
  - `workers/`: 后台异步/扫描/导出/转码 worker
- `app/api-gateway/`: 预留边界层入口；当前状态见 `README.md`
- `data/`: 运行依赖的 JSON 侧数据（按功能区分）
- `docs/`: 规范、设计、审计与截图
- `resources/`: 多语言、图标、底图等静态资源
- `scripts/`: 构建、维护与回归脚本
- `tests/`: 单测与 Qt UI 测试

## 权威文档

## 优化建议（持续执行）

- 变更新增文件时先放入对应目录，必要时更新本文件。
- 大型历史文档与计划稿与当前实现文档分开归档，避免主路径信息淹没。
- `app/api-gateway` 若长期不启用，可考虑归并至 `app/services`，并同步更新本说明。
